# content/telops/

モードB（手持ちの動画にテロップを付ける）のテロップ。

`npm run caption:asr -- --video <絶対パス>` が `<slug>.json` を書く。
**これは生成物ではなく入力。** 音声認識は固有名詞を外すので、人間が直して git に入れる。

```json
{ "text": "リモーションで", "startMs": 3200, "endMs": 4400 }
```

- 直すのは **`text` だけ**
- **`startMs` / `endMs` は触らない。** 音声から出ている唯一の根拠で、
  動かすと音とテロップがずれる
- 直したら `npm run caption -- --video <同じパス>`（認識は飛ばして焼き直す）
- `--force` は認識をやり直す。**手で直した内容は消える**

`slug` は「ファイル名 + 絶対パスのハッシュ」。別フォルダの同名ファイルと衝突しない。
