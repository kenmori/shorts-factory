# 画像素材

`visual: { kind: "image", shots: [...] }` がここのファイル名を参照する。

`placeholder-*.png` は `scripts/dev/make-placeholder-shots.ts` が生成した**仮の絵**。
切り替えが効いているかを見るための置き石なので、**実素材に差し替える。**

## 何を置くか

題材で変わる。優先順位はこの順。

1. **実スクリーンショット** — AIツールや技術の紹介なら現物の画面が一番強い。
   無料で信頼性が高い。抽象的な生成画像は量産感が出て逆効果になりやすい
2. **図・グラフの画像** — テンプレの `chart` で描けないもの（アーキテクチャ図など）
3. **生成画像** — 見せる画面が無いネタ（速報・抽象的な発表）向け。
   AI生成物なので投稿時の申告対象（`publish.json` に注記は入っている）

## 決まり

- 縦型なので**縦長（3:4 前後）**が収まりがよい。横長は上下が切れる
- 1080px 以上の幅。小さい画像は拡大されて粗く見える
- **権利を確認したものだけ置く。** 3媒体すべてで使える必要がある
- 大きいファイルは git に入れない（`public/screencasts/` は gitignore 済み）
